# MCP Webinar Demo

This repo provides a Node app that is being used in various MCP demos using the Docker MCP Catalog and Toolkit.

## Project setup

This project has purposely been downgraded on a few versions of application dependencies and external services to demonstrate upgrading the services using AI-based workflows.



## Sample prompts

> Help me complete the work for issue #1 for this project.

This will require the GitHub and Docker Hub MCP servers to fetch the details and updated tags.

> Let's complete issue #2, commit the code on a new branch, and create a pull request

This will require the GitHub MCP server to get the issue details and create a PR.
